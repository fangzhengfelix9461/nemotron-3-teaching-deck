# NVIDIA Nemotron 3 research presentation

English, 20-slide HTML presentation with deterministic teaching demonstrations and original paper figures. The Chinese outline is linked from the presentation.

The presentation discusses the December 2025 model-family white paper, [NVIDIA Nemotron 3: Efficient and Open Intelligence](https://arxiv.org/abs/2512.20856). Model-specific designs, computed teaching examples and reported measurements are labelled separately.

## Viewing

Open the repository's GitHub Pages site or download and open `nemotron-teaching.html`. Use the bottom arrows to change slides. On demonstration slides, use Next step, Back, Reset or Play. Original figures and tables can be enlarged.

Slides 15–20 are the condensed ending, with five manual animation advances across three demonstrations. The first fourteen slides retain their existing content and interaction.

## Hosting

GitHub Pages serves the root of the `main` branch. `index.html` opens the presentation and preserves query parameters and slide anchors. No server, API key, build dependency or model download is needed.

This repository contains only the published HTML artifacts. Original paper figures retain their source attribution and belong to their respective authors.
